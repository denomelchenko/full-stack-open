# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user writes a note and clicks Save
    Note right of browser: The JavaScript handler prevents the default form submit, so no page reload happens
    Note right of browser: The new note is added to the local notes array and the notes list is re-rendered immediately

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of server: The request body is JSON: { "content": "...", "date": "..." }
    Note right of server: The server stores the note and does NOT redirect
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: The response carries no HTML, so the browser never reloads and never re-fetches data.json
```
